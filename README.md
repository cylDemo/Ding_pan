# 盯盘 · 桌面浮窗

> 一个常驻桌面的极简行情浮窗：**京东黄金 + A 股自选股 + 板块强度**，免登录、免安装、不写注册表、不驻留后台服务。

基于 Python + tkinter 编写的 Windows 桌面小工具，启动后以无边框浮窗形式停靠在屏幕右上角，实时监控黄金价格与自选股行情，一眼可见、随手可用。适合上班族在办公场景下**不切窗口**地掌握盘中关键信息。

## 功能特性

| 区域 | 能力 |
|---|---|
| **金价区** | 京东金融公开行情：现货金、伦敦金、多家银行积存金等，约 5 秒刷新 |
| **股票区** | 自选股实时价格与涨跌幅，约 2 秒刷新；支持超过 3 只时滚轮滚动 |
| **板块区** | 概念/行业板块强度排名，支持东方财富板块代码（`BK` 开头）与同花顺板块指数（`885xxx` / `886xxx`） |

**交互能力**

- **拖动**：按住浮窗任意处即可移动位置
- **双击标题栏**：迷你视图 / 标准视图切换
- **分区收起**：金价区、股票区、板块区均可独立收起 / 展开（右缘箭头），重启后保持状态
- **隐私模式 👁**：所有行情数据以 `****` 显示，适合开放工位；掩码生效时图标变蓝
- **主题切换 ☼**：深色 / 浅色一键切换
- **右键菜单**：立即刷新、置顶、主题、收起金价区、透明度循环、打开网页看板、退出
- **一键隐藏**：标题栏 `—` 立即隐藏浮窗（不进任务栏、不占 Alt+Tab），`Ctrl + Alt + D` 唤回，位置与大小不变
- **全局快捷键**：`Ctrl + Alt + D` 隐藏 / 唤出浮窗（无需切回窗口）
- **股票搜索**：输入名称或代码即时搜索，点选结果加入自选，🗑 删除

**工程特性**

- **纯标准库运行时**：除 tkinter 外无第三方运行时依赖，打包后无需安装 Python
- **免登录**：全程不涉及任何账号体系，无用户数据上传
- **配额友好**：金价仅在工作日 9:30~18:00 拉取（其余时段静默），避免空耗接口配额；行情失败自动退避重试，且**保留上一次数据不闪空**
- **配置原子写**：配置写入采用临时文件 + `os.replace`，异常断电不会损坏配置文件
- **自带日志系统**：`~/.gold_widget.log`，1MB × 3 轮转，自动对本机绝对路径脱敏

## 快速开始

1. 下载并解压到任意位置（例如 `D:\盯盘`）
2. 双击 `盯盘.exe`，浮窗出现在屏幕右上角
3. 建议右键 `盯盘.exe` →「发送到」→「桌面快捷方式」

**系统要求**：Windows 10 / 11 64 位。请先完整解压再运行，不要在压缩包内直接双击。

## 隐私与安全说明

本工具的设计目标是**最小信任面**：

- ✅ 不写注册表
- ✅ 不设置开机自启
- ✅ 不驻留后台服务、不安装任何驱动
- ✅ 无联网上报、无用户数据采集
- ✅ 内置网页看板仅监听本机 `127.0.0.1`，不对局域网开放
- ✅ 日志自动对本机绝对路径脱敏

**关于杀毒软件误报**

程序**未做商业代码签名**，这是被杀软判为「未知发布者」的主要原因。

- **绿色版**：打包形态为「文件夹 + 独立运行时」，通常不会被误报
- **单文件版**：所有内容压在单个 exe 内，属启发式引擎的高敏感形态，偶有误报

如遇提示，添加信任 / 白名单即可，不影响功能。

## 从源码构建

```bat

python -m venv .build_venv

:: 2. 安装打包工具
.build_venv\Scripts\pip install pyinstaller
```

## 常见问题

**Q：双击没反应？**
需要 Windows 10 / 11 64 位系统；确认已完整解压后再运行，不要在压缩包内直接双击。绿色版若提示缺少 DLL，通常是 `exe` 与 `_internal` 被拆开，或 `_internal` 内文件被杀软隔离了。

**Q：板块数据显示 `---`？**
这是网络抖动时的正常兜底（会保留上一次数据并自动重试）。若持续显示，检查网络后右键「立即刷新」。

**Q：金价长时间不更新？**
金价配额仅在工作日 9:30~18:00 使用，非该时段界面会显示「非刷新时段」，这是有意设计，避免空耗接口配额。
